{{- if and .Values.perPerson.enabled (not .Values.perPerson.keepShared) }}

Each person's own O'Reilly access is on and no shared-key O'Reilly server is registered, so
fitness runs and kmctl, which have no O'Reilly sign-in, get "connect your O'Reilly account". Run
the O'guide fitness suites with perPerson off until tool names are scoped per server.
{{- end }}
{{- if and .Values.perPerson.enabled .Values.perPerson.keepShared }}

Each person's own O'Reilly access is on and the shared-key server is kept beside it
(perPerson.keepShared=true). Both list the same O'Reilly tool names and the gateway routes a call by
tool name, so a call may reach either, including the shared key for a per-person call. Set
perPerson.keepShared=false where the result must be per person.
{{- end }}
